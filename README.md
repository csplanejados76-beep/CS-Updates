# CS Updates

Canal público de distribuição de atualizações do **Ecossistema CS**.

Este repositório **não contém o código-fonte comercial**. Ele existe somente para publicar instaladores e checksums usados pelos botões **ATUALIZAR** dos aplicativos.

## Padrões de arquivos

### CS Router
- `CS_Router_Setup_Vx.y.z.exe`
- `CS_Router_Setup_Vx.y.z.exe.sha256`

### CS Serras
- `CS_Serras_Setup_Vx.y.z.exe`
- `CS_Serras_Setup_Vx.y.z.exe.sha256`

### CS3D Desktop
- `CS3D_Desktop_Setup_Vx.y.z.exe`
- `CS3D_Desktop_Setup_Vx.y.z.exe.sha256`

### CS Orçamento Fácil (Android)
- `CS_Orcamento_Facil_Vx.y.z.apk`
- `CS_Orcamento_Facil_Vx.y.z.apk.sha256`

## Segurança

Cada aplicativo compara sua versão instalada com as GitHub Releases deste canal. O instalador só é executado depois da verificação do SHA-256 publicado junto da release.

O licenciamento comercial continua separado no **CS License**. Disponibilizar os instaladores neste repositório não libera o uso do software sem uma licença válida.
